\begin{frame}{Crys-JEPA screening score}
For a relaxed candidate $c$, retrieve training crystals whose elements lie within the candidate's chemical system:
\[
R(c)=\{r\in\mathcal D_{\mathrm{train}}:\mathrm{elements}(r)\subseteq\mathrm{elements}(c)\}.
\]
The ranking score is the mean squared distance in Crys-JEPA embedding space:
\[
 s(c)=\frac{1}{|R(c)|}\sum_{r\in R(c)}\|h_c-h_r\|_2^2.
\]
\begin{itemize}\setlength\itemsep{2mm}
\item For an $AB_2$ candidate, eligible references include $A$, $B$, and known $A$--$B$ phases.
\item Each retrieved reference contributes equally. Smaller scores rank first.
\item The score measures proximity in an energy-aware representation; it is not an explicit energy-above-hull calculation (this is our understanding).
\end{itemize}
\source{Existing scoring rule: Crys-JEPA \cite{liu2026crysjepa}.}
\end{frame}

% 4
\begin{frame}{Limitations of the reference pool}
\begin{itemize}\setlength\itemsep{4mm}
\item \textbf{Chemical-system restriction.} The original pool excludes outside-system crystals that may contain transferable structural or chemical information.
\item \textbf{Unequal information, equal weights.} References can differ in relevance and redundancy, but the score assigns equal weight to each.
\item \textbf{No explicit joint competition.} Pairwise distances do not directly represent composition-balanced alternatives such as $AB+B$ for $AB_2$.
\item \textbf{Reference-set dependence.} Adding references changes both the centroid and spread of their embeddings, and therefore the average-distance score.
\end{itemize}
\vspace{3mm}
These observations motivate experiments. We are claiming theoretically that this can be improved.
\end{frame}

\begin{frame}{Proposed reference graph}
\begin{columns}[c]
\column{.48\textwidth}
\centering
\referencegraph
\column{.49\textwidth}
\begin{itemize}\setlength\itemsep{3mm}
\item \textbf{Competition references:} crystals using the candidate's elements.
\item \textbf{Cross-chemistry analogues:} crystals with relevant structural or chemical similarities.
\item Build a broad search pool using chemical seeds, similarity search and graph expansion; attach the candidate as a query node.
\item Learn candidate-specific reference relevance, then return ranked reference crystals with scores.
\end{itemize}
\end{columns}
\vspace{3mm}
Analogues supply predictive context. They cannot be decomposition products when they introduce elements absent from the candidate.
\end{frame}

% 6
\begin{frame}{Learning which reference crystals to select}
\begin{columns}[c]
\column{.37\textwidth}\centering
\screeningtransformer
\column{.60\textwidth}
\textbf{Candidate-conditioned reference selection}
\begin{itemize}\setlength\itemsep{0.5mm}
\item Use composition, structural similarity and graph expansion to form a broad search pool from the permitted database.
\item A graph transformer produces contextual candidate and reference states $z_c,z_r$ using typed relationships.
\item A pairwise head assigns a relevance score $s(c,r)$ to each potential reference $r$ for candidate $c$.
\item \textbf{Output: ranked reference crystals and their relevance scores}, followed by selection under a reference budget $k$.
\end{itemize}
\par\vspace{1mm}
\small Reference relevance is distinct from candidate stability. A separate downstream comparison uses the selected references to rank candidates.
\par\vspace{1mm}
\small\textbf{Open choice:} how to train reference relevance. One option is supervision through a downstream screening objective, rather than assumed ``correct reference'' labels.
\end{columns}
\end{frame}

\begin{frame}{Using reference context during generation}
The same reference database graph may also inform how a candidate is constructed.
\vspace{4mm}
\begin{columns}[T]
\column{.47\textwidth}
\textbf{Selection-based refinement}
\begin{itemize}\setlength\itemsep{2mm}
\item Score completed candidates.
\item Select examples for generator fine-tuning.
\item References affect the generator indirectly through training data.
\end{itemize}
\column{.49\textwidth}
\textbf{Proposed direct conditioning}
\begin{itemize}\setlength\itemsep{2mm}
\item Retrieve references before generation.
\item Encode them as contextual tokens.
\item Let the denoiser consult these tokens through cross-attention.
\end{itemize}
\end{columns}
\vspace{4mm}
The initial scope chooses a target composition before generation. Any improvement over composition-only conditioning must be established experimentally.
\source{Composable Crystals motivates reusable structural conditioning \cite{liu2026composable}; MatterGen provides diffusion-generation context \cite{MatterGen2025}.}
\end{frame}

% 10
\begin{frame}{Reference graph encoder}
\begin{columns}[c]
\column{.45\textwidth}\centering
\graphcell{LayerNorm + Linear\\$R\in\mathbb R^{n\times d_{\mathrm{ref}}}$}
\column{.53\textwidth}
\begin{itemize}\setlength\itemsep{3mm}
\item Input: frozen Crys-JEPA embeddings and composition features for retrieved references.
\item Typed graph attention contextualizes each crystal using its neighbours.
\item Output: one vector per reference, $R\in\mathbb R^{n\times d_{\mathrm{ref}}}$; no global pooling.
\item The generation GNN learns through the denoising loss. Its weights initially differ from the screening GNN's.
\end{itemize}
\vspace{2mm}\small Whole-crystal tokens provide compressed context. They do not directly encode transferable local atomic geometries.
\end{columns}
\end{frame}

% 12
\begin{frame}{Training and inference}
\begin{columns}[T]
\column{.49\textwidth}
\textbf{Training}
\begin{enumerate}\setlength\itemsep{2mm}
\item Choose a labelled training crystal and its composition.
\item Retrieve references using composition; exclude the target and equivalent duplicates.
\item Encode the reference subgraph.
\item Corrupt the training crystal at a sampled diffusion timestep.
\item Optimize the standard denoising loss through the graph encoder, cross-attention and selected denoiser weights.
\end{enumerate}
\column{.49\textwidth}
\textbf{Inference}
\begin{enumerate}\setlength\itemsep{2mm}
\item Specify the requested composition.
\item Retrieve and encode references once.
\item Sample from the diffusion prior and denoise with reference conditioning.
\item Relax the result and apply validity, uniqueness and novelty checks.
\item Retrieve using the completed structure, screen, and select candidates.
\end{enumerate}
\end{columns}
\vspace{3mm}\small Currently, inference does not update weights. Selected outputs may support a later refinement round (include with the Crys-JEPA flow)
\end{frame}

\begin{itemize}
\item Include composition-only conditioning and unordered-reference controls.
\item Compare relevant and shuffled references; vary reference count.
\item Match training data, target compositions, sample counts and refinement budgets.
\end{itemize}

\textbf{Open design choices}
\begin{itemize}\setlength\itemsep{3mm}
\item Fix atom identities/counts, or condition atom-type diffusion on composition.
\item Select graph edges, retrieval budget and graph-encoder depth.
\item Choose which denoiser weights to fine-tune.
\item Consider balanced mixture nodes only if initial screening results motivate them.
\end{itemize}
\end{columns}

% 14
\begin{frame}{Validation of generated crystals}
\begin{itemize}\setlength\itemsep{3mm}
\item \textbf{Before selection:} measure relaxation success, validity, uniqueness, novelty, diversity and chemical coverage over the full sampled pool.
\item \textbf{After selection:} independently evaluate the same budget from each generator/screener combination using compatible DFT and hull protocols.
\item \textbf{Discovery yield:} report independently validated stable or near-hull, unique, novel candidates per generated sample, alongside yield per validated candidate.
\item \textbf{Reference dependence:} measure similarity to retrieved crystals and control near-duplicates across data splits.
\item \textbf{Cost and failures:} include generation, retrieval, screening and validation overhead; report unsuccessful calculations.
\end{itemize}
\vspace{3mm}
Improvement requires higher independently validated yield, not only greater agreement with the learned screening model.
\end{frame}
